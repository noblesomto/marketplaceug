 VALIDATION SYSTEM
═══════════════════════════════════════════════════════════════════════════

The validation system uses DYNAMIC RULES based on category/subcategory:

BASE FIELDS (All Categories):
  • ad_title       - required|max:75
  • category       - required
  • subcategory    - required
  • brand          - required
  • state          - required
  • lga            - required
  • description    - required|max:3500
  • images         - required|array (except Jobs category)

CATEGORY-SPECIFIC FIELDS:

  Fashion/Electronics/Real Estate:
    • price          - required|numeric
    • price_type     - required
    • item_condition - required
    • quantity       - optional

  Vehicles (Cars/Buses/Motorcycles):
    • model          - required
    • registration   - required
    • mileage        - required|numeric
    • condition      - required
    • fuel           - required
    • transmission   - required
    • vehicle_type   - required
    • doors          - required

  Mobile Phones:
    • model          - required
    • phone_color    - required
    • phone_condition- required
    • device         - required

  Jobs:
    • salary         - required
    • price          - hidden/not required
    • images         - optional

  CVs:
    • expected_salary- required
    • price          - hidden/not required
